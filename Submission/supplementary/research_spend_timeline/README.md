# Research timeline

`timeline.pdf` is a short, dated timeline of how the research was conducted (21 to 26 October 2026): milestones, effort as recorded, deviations and what was not run.
`timeline.html` is its source; print it to PDF in a browser to rebuild it.
Every date and count comes from the daily notes in `2026/2026-10/`, the results note, the disclosure log and the git log; nothing is estimated.
The report cites this folder in its Methods and Code and Data sections.
