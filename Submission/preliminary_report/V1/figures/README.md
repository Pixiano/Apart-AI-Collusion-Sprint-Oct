# Figures

Made by `make_figures.py` (matplotlib, reads `data/` only; also writes `../RESULTS_TABLE.md`). Index = (mean price - 10) / 45. Gate rule: base run has 30 rounds and index over rounds 16-30 >= 0.5 (not applied in (d), and in (e) failing runs are drawn faint). Effect = index over rounds 31-60 minus the same run's no-swap branch (for comm-cut bars, the no-swap branch with messages also cut), 95% bootstrap interval over runs (10000 resamples, seed 0). The swap after round 30 is the dotted vertical line; 10 and 55 are grey horizontal lines in (a).
