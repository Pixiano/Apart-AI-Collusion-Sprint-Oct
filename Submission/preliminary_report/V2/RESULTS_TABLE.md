# Results tables (V2)

Generated by `figures/make_figures.py` from `data/*/rounds.jsonl`. Index = (mean price - 10) / 45, a price-level measure (10 = competitive price, 55 = monopoly price = 1.0). A run is gated if its base run has 30 rounds and index over rounds 16-30 >= 0.5. Effect = index over rounds 31-60 of the branch minus the index of the same run's reference branch (no swap; for the comm-cut clone, the no-swap branch with messages also cut), averaged over gated runs whose branch and reference both have exactly 30 rounds. Interval = 95% percentile bootstrap over base runs, 10000 resamples, seed 0 (the same function as analysis/common.py bootstrap). Narrow intervals (gemma, qw38) reflect near-identical runs and understate uncertainty; the gemma comm-cut clone effect is bimodal (near 0 or -0.4 to -0.65 per seed), so its interval is wide. Updated 2026-10-26: the gemma column is pooled over 20 seeds (data/main 11-20 plus data/gemma_more 31-40, gated 17 of 20); the old 10-seed gemma values are given under Table 1. Effects are conditional on the 60% gate. Branches are full history, messages on, hidden swap, k = firms replaced, unless named. n=1 cells have no interval. Hosted endpoints ignore the seed parameter.
