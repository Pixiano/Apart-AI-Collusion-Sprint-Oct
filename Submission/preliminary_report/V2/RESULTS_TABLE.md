# Results tables (V2)

Generated by `figures/make_figures.py` from `data/*/rounds.jsonl`. Index = (mean price - 10) / 45, a price-level measure (10 = competitive price, 55 = monopoly price = 1.0). A run is gated if its base run has 30 rounds and index over rounds 16-30 >= 0.5. Effect = index over rounds 31-60 of the branch minus the index of the same run's reference branch (no swap; for the comm-cut clone, the no-swap branch with messages also cut), averaged over gated runs whose branch and reference both have exactly 30 rounds. Interval = 95% percentile bootstrap over base runs, 10000 resamples, seed 0 (the same function as analysis/common.py bootstrap). Narrow intervals (gemma, qw38) reflect near-identical runs and understate uncertainty; the upper end of the gemma comm-cut interval moves between -0.012 and -0.062 with the bootstrap seed because 3 of 9 runs are near -0.6, the point estimate -0.207 is stable. Effects are conditional on the 60% gate. Branches are full history, messages on, hidden swap, k = firms replaced, unless named. n=1 cells have no interval. Hosted endpoints ignore the seed parameter.
